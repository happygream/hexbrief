# Changelog

## [1.0.3] — 2026-06-22

- Streamlined one-click installer with branded install screen
- Installs and launches automatically

## [1.0.2] — 2026-06-22

- Fixed installer layout — frameless window now renders correctly without clipped content
- Draggable custom titlebar
- New application icon — HB monogram, sharp at all sizes

## [1.0.1] — 2026-05-26

- Full custom branded installer — dark navy sidebar on every screen, no Windows chrome
- New widgets: Habits tracker with streaks, Countdowns, Finance (FX + crypto), Quick capture inbox, Bookmarks, Notes
- Pomodoro timer in tasks widget with desktop notifications
- Auto-start with Windows toggle in settings
- One-click weather location detection
- Smart greeting with task count and next calendar event
- Incomplete tasks roll forward to next day automatically
- DM Sans font throughout for improved readability
- Security hardening: SSRF protection, input sanitisation, sandbox mode, tighter CSP
- Clean uninstaller — removes all app data, shortcuts and registry entries

## [1.0.0] — 2026-05-22

Initial release.

- Weather widget with Open-Meteo (no API key required)
- Tasks with progress tracking
- Focus intention — resets daily
- Calendar via iCal URL
- Headlines from configurable RSS feeds
- Widget picker — add, remove, reorder, assign to column
- Desktop app for Windows, macOS, Linux via Electron
